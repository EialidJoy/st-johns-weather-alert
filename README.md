# St. John's Weather Alert System

A real-time weather monitoring and alert system for St. John's, Newfoundland and Labrador.

## Features (Planned)
- Current weather data for St. John's
- Severe weather alerts (wind, fog, temperature)
- 5-day forecast
- React-based dashboard

## Tech Stack
- **Backend:** Python FastAPI
- **Frontend:** React (coming soon)
- **APIs:** Environment Canada / OpenWeatherMap

## Setup
```bash
# Install dependencies
pip install fastapi uvicorn requests

# Run the app
uvicorn main:app --reload
```
